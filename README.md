# ResQTh

ResQTh is an intelligent emergency response and post-incident action guide designed for people in Thailand, especially foreign residents and visitors who may not know the appropriate emergency contacts or procedures.

The system helps users quickly access relevant emergency information based on their location, situation, and urgency level. For high-urgency situations, ResQTh provides immediate-response tools such as one-tap emergency hotline access, localized assistance information, and GPS coordinate sharing. For lower-urgency or post-incident situations, it provides step-by-step guidance, incident note logging, and directions to appropriate official facilities.

ResQTh also includes an AI-assisted natural-language search feature that allows users to describe situations such as "I lost my passport in Phuket." The system identifies the relevant emergency category, location, and urgency level and directs the user to the appropriate information and actions.
